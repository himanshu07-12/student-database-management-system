# Student Database Management System

A web-based Student Database Management System developed using Python, Flask, and MySQL.

## Features

- User Login
- User Signup
- Add Student
- View Students
- Update Student
- Delete Student
- Login History

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap
- Git
- GitHub
